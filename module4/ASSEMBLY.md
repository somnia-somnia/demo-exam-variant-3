# Модуль 4: сборка и завершение проверки в редакторе

Это инструкция только по графическому макету, не итоговое руководство по
воспроизведению всего экзамена. Основной файл — `Группа-Таймыр.sketch`.
PNG — точные визуальные референсы, они не заменяют редактируемый формат.

05.11.2026 проверены доступные приложения Windows и коннекторы: Figma, Sketch,
Adobe XD и Pixso не обнаружены среди установленных редакторов; коннектор Figma
не подключён. Открытие файла и проигрывание прототипа здесь недоступны.
Архив Sketch содержит редактируемые слои, а не два вставленных скриншота.
Синтаксис и структура проверены официальной схемой; нативный hover отсутствует.

1. Установите Roboto Regular и Bold из `assets`. Откройте основной `.sketch`
   в поддерживающем его редакторе. Проверьте, что текст выделяется как текст,
   логотип и фото — отдельные изображения, кнопки — группы фигур и подписей.
   При импорте в другой редактор проверьте сохранность связей Prototype.
2. Если импорт недоступен, создайте один новый документ с двумя фреймами
   `01 · Главная` и `02 · Решения`, каждый 430×932 px, портрет. PNG используйте
   как временную подложку; итог собирайте отдельными слоями, подложку удалите.
   В `layer-specification.csv` указаны абсолютные координаты, размеры, тексты
   и стили всех видимых слоёв, считанные непосредственно из Sketch.
3. Для каждого фрейма задайте 4 колонки по 89 px, промежутки 14 px, поля 16 px.
   Рабочая ширина 398 px: 4×89+3×14+2×16=430. Фон `#F5F8F8`.
   Основной цвет `#0E7583`, текст `#17363B`, вторичный `#536A6E`,
   линии `#D5E3E5`, белые карточки, радиус карточек 8 px, кнопок 6 px.
4. Создайте четыре текстовых стиля: Roboto Regular 14/18; Bold 14/18;
   Bold 16/20; Bold 28/34. Значения после `/` — межстрочное расстояние.
   Не уменьшайте текст для размещения длинных пунктов. Тексты берите дословно
   из `../docs/original/Текст.docx`; порядок уже отражён в CSV и референсах.
5. На обоих экранах разместите полный `assets/logo.png`: x=16, y=12,
   ширина 132 px, высота пропорциональна оригиналу. Под ним меню:
   «Главная» (16,48,192,40), «Решения» (222,48,192,40).
   Активный пункт заполнен основным цветом, подпись белая; второй белый с
   бирюзовым контуром и подписью. Навигационная зона занимает y=0…96.
6. Главная: поиск (16,108,398,44), подпись категории (16,174), заголовок
   (16,202,398,68), фото `assets/photo.jpg` (16,282,398,110).
   Описание начинается (16,408), ширина 398. Ниже три преимущества в исходном
   порядке; точные рамки в CSV. Кнопки: «Заказать лицензию» (16,648,398,44),
   «Скачать пробную версию» (16,700,398,44). Линия подвала y=758,
   юридический текст y=772; © 2025 и «Все права защищены» — y=820.
7. Решения: две карточки шириной 192 px, x=16 и x=222.
   Первый ряд y=100, высота 330; второй y=440, высота 276;
   третий y=726, высота 158. Внутренний отступ 12 px.
   Слева направо и сверху вниз: Studio/Server, Mobile/Embedded,
   «Программный стек „Группы Таймыр“»/«Техническая поддержка».
   Названия и пункты копируйте из DOCX с оригинальными кавычками.
   Кнопки «Подробнее»: x=28/234, y=378/664/832, размер 168×40.
   Подвал начинается y=896. Последний видимый текст заканчивается y=914.
8. Во вкладке Prototype назначьте первому экрану старт. На обоих экранах
   по нажатию «Главная» ведёт на первый фрейм, «Решения» — на второй.
   Переход мгновенный. Самопереход активного раздела можно оставить.
   Восемь остальных кнопок оставьте без переходов; поиск — визуальный элемент.
9. Обязательно подключите hover в самом редакторе: над нормальным меню
   разместите образцы из скрытой группы «Состояния / hover меню · спецификация».
   Скрытый родитель не должен блокировать hover дочерних слоёв: вынесите
   каждый образец в видимую навигационную группу. Для слоя образца в современном
   Sketch: Prototyping → Visibility → `+` → Action `Show`, Trigger `Hover`.
   Hover должен менять цвет подписи на `#085966`, фон на `#EAF3F4` только в
   пределах своего пункта. Сохраните тот же переход по нажатию и проверьте,
   что верхний слой его не перехватывает. В редакторе с вариантами компонентов
   используйте состояния Default/Hover и While hovering → Change to Hover.
   Добавлять третий экран не нужно. Эти действия в поставленном файле пока
   не выполнены; скрытые образцы сами по себе не являются работающим hover.
10. Запустите Preview: переход туда и обратно, наведение каждого пункта,
    восемь кнопок без переходов, отсутствие обрезки, пропавших изображений
    и подменённых шрифтов. Сравните с обоими PNG при масштабе 100%.
    Сохраните один нативный файл `.sketch`, `.fig` либо `.xd`, закройте и
    откройте повторно. PNG/HTML не сдавайте вместо этого файла.

Основания: [официальный открытый формат Sketch](https://developer.sketch.com/file-format/),
[официальные настройки Hover/Visibility](https://www.sketch.com/docs/prototyping/customizing-layer-visibility/).
Автоматическая проверка: `python module4/verify_design.py` (Pillow и jsonschema
нужны только инструменту проверки; для запуска сайта они не нужны).
