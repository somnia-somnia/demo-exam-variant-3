# Модуль 4 — «Группа Таймыр»

Основной файл — **`Группа-Таймыр.sketch`**, редактируемый ZIP/JSON-документ Sketch с двумя экранами 430 × 932 px. В нём отдельные текстовые, векторные и растровые слои, четыре нативные связи переходов. Это файл открытого формата Sketch 146, проверенный по официальной схеме 6.5.0.

**Статус: PARTIAL.** Наведение меню не реализовано как нативное событие. Открытие в редакторе, CoreText и проигрывание переходов не проверены. Структурная проверка не подтверждает эти свойства. Подробная сверка с оригинальным заданием — в `AUDIT.md`, машинные результаты — в `verification-report.json`.

Повторная проверка 05.11.2026: автоматические проверки прошли; установленного
редактора и подключённого Figma-коннектора нет. Для завершения в редакторе
подготовлена [инструкция только по модулю 4](ASSEMBLY.md) и точные координаты
редактируемых слоёв в `layer-specification.csv`. Генератор сайта к модулю 4 не относится.

В комплекте сохранены:

- `Группа-Таймыр.sketch` — единственный основной макет;
- `01-home.png`, `02-solutions.png` — справочные изображения Pillow, **не экспорт Sketch**;
- `assets/` — исходный логотип, фото и его кадрирование, Roboto Regular/Bold и OFL;
- `build_design.py`, `verify_design.py` — сборка и независимое чтение итогового архива;
- `sketch-file-format-6.5.0.schema.json`, `schema-LICENSE.txt` — официальная схема и MIT.

Воспроизводимые проверки используют Python с Pillow и jsonschema, исходники `source/Медиа/Медиа` и `docs/original/Текст.docx`. `verify_design.py` читает именно `.sketch`, не запускает генератор и не проверяет дубликат JSON. Пакеты в сеть не загружаются. Повторная сборка генерирует новые ID, поэтому хеш архива изменяется.

Сетка: 4 × 89 px, промежутки 14 px, поля 16 px. Типографика: Roboto Regular 14/18, Bold 14/18, 16/20 и 28/34. Основной цвет `#0E7583` согласован с исходным логотипом. Все восемь кнопок действий не имеют переходов по заданию. Поиск представлен как элемент макета; программная реализация заданием не требуется.

Вспомогательный HTML не используется как результат модуля. Предпросмотр внутри
архива создан Pillow. Итоговое руководство по ручному воспроизведению всего
экзамена в этой итерации не создавалось.
