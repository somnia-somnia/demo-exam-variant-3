# Ручная сборка и финальная проверка модуля 4

Инструкция относится только к двум экранам «Группы Таймыр». Она не затрагивает веб-приложение аренды автомобилей из модулей 1–3.

## Быстрый путь с готовым Sketch

1. Установите оба шрифта из `assets`: Roboto Regular и Roboto Bold.
2. В Sketch откройте `Группа-Таймыр.sketch`. Если используете Figma, импортируйте этот файл в новый документ. В Adobe XD проверьте доступный импорт Sketch; совместимость конкретной версии импорта здесь не проверялась.
3. Убедитесь, что на одной странице ровно два экрана 430 × 932 и текст выделяется инструментом редактирования текста. Отдельно проверьте нижние карточки и подвал второго экрана.
4. Сравните экраны с `01-home.png` и `02-solutions.png` при масштабе 100%. Эталон не заменяет редактируемые слои.
5. Выполните настройку hover и проверьте переходы ниже. Сохраните документ средствами редактора в `.sketch`, `.fig` или `.xd`.

## Если требуется собрать полностью вручную

Создайте новый документ и два фрейма/артборда 430 × 932 px. Назовите их `01 · Главная` и `02 · Решения`. На каждом добавьте четырёхколоночную сетку: ширина содержимого 398, поля 16, gutter 14, колонки по 89. Фон `#F5F8F8`.

Создайте четыре текстовых стиля:

| Стиль | Шрифт | Размер / строка | Цвет |
| --- | --- | --- | --- |
| Заголовок платформы | Roboto Bold | 28 / 32 | `#17363B` |
| Заголовок карточки | Roboto Bold | 16 / 20 | `#0E7583` |

Для вторичного текста используйте тот же основной стиль с цветом `#536A6E`. Это вариант цвета, а не новое начертание или размер.

### Переходы во вкладке «Прототип»

1. Установите первый экран как начальную точку.
2. На первом экране выберите всю группу «Меню / Решения», а не только буквы. Создайте переход по Tap/Click на `02 · Решения`, Instant / без анимации.
3. На втором экране назначьте группе «Меню / Главная» Tap/Click → `01 · Главная`.
4. Для текущего пункта допустима ссылка на свой экран: она уже записана в готовом `.sketch`.
5. Остальным кнопкам переходы не назначайте. Прокрутка не требуется, размеры монтажных областей остаются 430 × 932.

### Hover: обязательный ручной шаг для нативного результата

В исходном сгенерированном `.sketch` имеются обычные click-переходы. Его опубликованная схема формата 146 не содержит современных событий hover. Состояние наведённого пункта подготовлено отдельными текстовыми и фигурными слоями внутри скрытой группы «Состояния / hover меню · спецификация», однако событие к нему ещё не привязано.

В современном **Sketch 100+**:

1. На первом экране включите видимость группы «Состояния / hover меню · спецификация». Найдите внутри `Главная / Hover` и `Решения / Hover`. Это группы по 192 × 40 на тех же координатах, что меню.
2. Для каждой hover-группы во вкладке прототипирования установите **Visibility → Custom → Show → Hover** (в новых версиях: `Visibility`, кнопка `+`, Action `Show`, Trigger `Hover`). Так состояние будет скрыто в покое и показано только при наведении. На холсте оно может оставаться видимым при настройке.
3. Hover-цвет текста `#085966`, фон `#EAF3F4`, обводка `#0E7583`. Положение и размер полностью совпадают с исходной кнопкой, чтобы не возникало сдвигов.
4. Назначьте hover-группам те же click-переходы, что соответствующим пунктам меню. Это нужно, чтобы появившийся верхний слой также принимал клик.
5. Повторите для второго экрана. Остальные элементы не меняют состояние при наведении.
6. Запустите проигрывание и проверьте: наведение меняет цвет, уход указателя возвращает обычное состояние, клик работает в обоих состояниях. Сохраните нативный `.sketch` заново.

В **Figma** после импорта: создайте компонент меню с вариантами `Default` и `Hover`, задайте `While hovering → Change to → Hover`, цвет текста/фона по значениям выше; ссылки `On click → Navigate to` задайте в обоих вариантах экземпляра. Сохраните локальную копию `.fig` через меню Figma. Нельзя переименовывать `.sketch` в `.fig`.

Официальная инструкция Sketch: [Customizing layer visibility](https://www.sketch.com/docs/prototyping/customizing-layer-visibility/).

## Проверка перед сдачей

Откройте финальный нативный файл повторно. Убедитесь, что текст редактируется, фотографии встроены, Roboto не заменён системным шрифтом, размер обоих экранов 430 × 932, сетка четырёхколоночная, все пункты из docx присутствуют, «Подробнее» не обрезаны, оба направления навигации работают. Для hover проверяйте реальное проигрывание, а не только цвет на холсте. При изменении переносов увеличивать размеры фреймов нельзя — корректируйте рамку текстового слоя и отступы, сохраняя текст ≥14 px и кнопки ≥40 px.

PNG-эталоны и браузерный `prototype.html` предназначены для сравнения и просмотра. Они не заменяют итоговый `.sketch` / `.fig` / `.xd`.
