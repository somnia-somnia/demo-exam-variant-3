# Ключ.на.старт — вариант 3

Работающий локальный сайт для модулей 1–3: Python 3.11, Flask, SQLite,
серверные HTML-шаблоны, общий CSS и 13 строк JavaScript для слайдера.
PHP, React, Node.js, сборщиков, CDN и сетевых ресурсов нет.
Модуль 4 «Группа Таймыр» находится отдельно в `module4/`.

## Запуск

Нужен установленный **Python 3.11 x64 для Windows**. На чистой копии проекта
в PowerShell из этой папки:

```powershell
python --version
python -m venv .venv311
.\.venv311\Scripts\python.exe -m pip install --no-index --find-links vendor/wheels -r requirements.txt
.\.venv311\Scripts\python.exe app.py
```

Открыть [сайт](http://127.0.0.1:5000). Администратор: **Admin / StartNET**.
Пользователь регистрируется самостоятельно. Завершение сервера — Ctrl+C.
Если `python` не найден или показывает 3.12, укажите путь к установленному
`python.exe` версии 3.11 в первых двух командах. Уже имеющаяся `.venv` в этой
рабочей папке создана на 3.12; новая `.venv311` не смешивает интерпретаторы.

При первом запуске автоматически создаётся `instance/rental.db`.
Данные сохраняются между запусками и в Git не включаются. Секрет сессии
случайный для каждого процесса: после перезапуска сервера нужно войти снова.
Старый `secret.key` не используется. Существующие данные не сбрасываются.
Переменные `RENTAL_DB` и `PORT` позволяют выбрать другую БД
и порт; папка указанной БД должна существовать. SQLite работает без отдельного
сервера. Пакеты для установки, изображения и шрифты уже лежат локально.

## Структура

```text
app.py                 маршруты, общее описание полей и проверки, роли, заявки, отзывы
db.py                  единственный класс DB, метод query и транзакции
schema.sql             users → bookings → reviews, ограничения и связи
templates/
  base.html            общая оболочка и навигация
  form.html            вход, регистрация, новая заявка, сообщения об ошибке
  bookings.html        личные заявки и панель администратора
static/
  style.css            адаптивность, Montserrat, палитра, микроанимации
  script.js            четыре слайда, интервал 3000 мс, стрелки
  img/, fonts/         локальные ресурсы и лицензия
vendor/wheels/         офлайн-пакеты Windows x64
docs/                  оригиналы, ER, сверка требований и результаты проверок
module4/               редактируемый Sketch, референсы, инструкция и проверки
tests/                 функциональные тесты и инструменты проверки
```

Маршруты: `/register`, `/login`, `/bookings`, `/bookings/new`, `/admin`.
После POST сервер перенаправляет браузер; формы и просмотр заявок работают
при отключённом JavaScript. Пользователь видит только свои заявки.
Администратор меняет статусы и фильтрует список. Отзыв доступен исключительно
после завершения аренды, один на заявку. Пароли хешируются, запросы
параметризованы, доступ и CSRF проверяются сервером, HTML отзывов экранируется.

## Проверки и ограничения

```powershell
.\.venv311\Scripts\python.exe -m unittest discover -s tests -v
.\.venv311\Scripts\python.exe tests/verify_database.py
.\.venv311\Scripts\python.exe tests/report_statistics.py
```

Проверено на Python **3.11.9**: 20 тестов, включая контроль бюджета и реальный HTTP-сервер
с четырьмя независимыми сессиями. Edge: 390×844 и 1440×1000, формы и ошибки,
статусы, фильтр, отзывы, XSS, слайдер и отсутствие внешних запросов.
Браузерный тест `tests/browser_check.py` требует Edge и websocket-client
только на машине разработчика. Проверяющим инструментам модуля 4 нужны
Pillow/jsonschema; для сайта они не требуются.

[Выполненные требования и ограничения](docs/REQUIREMENTS.md),
[точная статистика](docs/STATISTICS.md), [ER-диаграмма](docs/er.svg),
[тесты](docs/test-results.txt), [скриншоты](docs/screenshots/).

Сайт: **11 992 символа, 277 строк** — все 8 исходников плюс `requirements.txt`,
включая пробелы и переносы LF. До сокращения с тем же составом было 18 515 символов.
JS — 344 символа. Предел 12 000 проверяется тестом `tests/test_budget.py`.
При скорости 100–120 символов/мин один набор — **100–120 минут**. Бюджет кода
достигнут; полный экзамен за 120 минут с запасом пока не подтверждён хронометражем.
Статистика отделяет исходники от тестов, документации и бинарных ресурсов.

Сокращение достигнуто общим описанием полей и обработчиком трёх форм,
одним методом запросов БД и двумя короткими HTML-макросами. Интерфейс в одну
колонку; убраны необязательные фото карточек, счётчик слайдера, уведомления
об успехе и декоративные детали. Четыре слайда, стрелки на фото, локальный
Montserrat, заданная палитра, микроанимации и серверные проверки сохранены.
Навигация в кабинет — по логотипу, регистрация — по ссылке на странице входа.
В новой схеме не создаются необязательные `created_at` и индекс `bookings_user`;
существующие таблицы и их данные не изменяются. Совместимость со старой схемой
проверена отдельным сценарием. Вставки пользователей соответствуют фиксированному
порядку семи столбцов `users` в `schema.sql`.

[Основной макет модуля 4](module4/Группа-Таймыр.sketch) содержит отдельные
редактируемые слои и связи между двумя экранами. Структура проверена, однако
открытие в редакторе и Preview не проверены, нативный hover не реализован.
Есть [инструкция завершения только модуля 4](module4/ASSEMBLY.md),
референсы `01-home.png`/`02-solutions.png` и координаты всех видимых слоёв
в `layer-specification.csv`. PNG не выдаются за требуемый нативный формат.

SQLite выбрана по явному пункту 9 запроса; MySQL-совместимость не заявляется.
ER создана по фактическим метаданным SQLite; экспорт из графического клиента
СУБД не проверен. Адрес экзаменационного Git-сервера не предоставлен.

Итоговое руководство по ручному воспроизведению в этой итерации не создаётся.
Уже существующие `EXAM_REPRODUCTION.md`, `EXAM_CHEATSHEET.md`,
`CHATGPT_TUTOR_PROMPT.md` и старый `docs/REWRITE.md` относятся к предыдущей версии;
они сохранены и не являются актуальной инструкцией для этого варианта кода.
