# Ключ.на.старт — обычный HTML и JavaScript

Python/Flask + SQLite, без Jinja-шаблонов, React, Node, CDN и сборки.
Модуль 4 «Группа Таймыр» отдельно в module4, без изменений.

## Запуск без интернета

Python 3.12x64 Windows, локальные пакеты уже лежат в vendor/wheels:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links vendor/wheels -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

[Открыть сайт](http://127.0.0.1:5000/login). Администратор: **Admin / StartNET**.
Остановка Ctrl+C. Другая БД — RENTAL_DB, другой порт — PORT. Папка выбранной БД должна существовать.
instance/rental.db и secret.key сохраняются между запусками и не попадают в Git.
Существующая БД совместима: схема не менялась, данные при переписывании не сбрасывались.

## Шесть исходников сайта

- app.py — страницы, JSON/API, серверная валидация, сессия, роли, заявки/отзывы.
- db.py/schema.sql — класс SQLite, PK/FK/UNIQUE/CHECK, те же три таблицы.
- static/index.html — обычные формы и HTML template карточки, без специальных скобок Jinja.
- static/script.js — fetch/FormData, безопасное textContent, карточки, навигация и слайдер.
- static/style.css — локальный Montserrat, палитра, адаптивность и микроанимации.
- static/img и fonts — те же девять фото/логотипов, три шрифта и лицензия.

GET/login,/register,/bookings,/bookings/new,/admin сохранены. GET/api возвращает csrf,
минимальный профиль и отфильтрованные на сервере заявки. Гостю — rows[] и user:null.
POST по прежним адресам теперь возвращает JSON next с 200; переход делает браузер.
Ошибки 400/403/404/409 также JSON для POST/API, на формах видны сообщения. GET-ошибки стандартные.
Браузеру нужен JavaScript. Jinja2 остаётся служебной транзитивной зависимостью Flask,
но в приложении не используются render_template, макросы или Jinja-разметка.

## Проверка и подготовка к экзамену

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверены 18 тестов,62 реальных HTTP-проверки, Edge390×844/1440×1000,4 слайда/3 секунды,
обе стрелки, ошибки, роли/владельцы, статусы/отзывы и XSS как текст. Браузерная проверка
`python tests/browser_check.py` требует Edge и websocket-client только для разработки.
Pillow/jsonschema также нужны только инструментам модуля 4, не сайту.

[Полное руководство](EXAM_REPRODUCTION.md), [шпаргалка](EXAM_CHEATSHEET.md),
[точная статистика](docs/STATISTICS.md), [итог переписывания](docs/REWRITE.md).
Объём: **20527 символов / 454 строк**, на 31.83% меньше исходных 30 110 символов.
Сохранение читаемости важнее выжимания последней строки. Лишние тексты/декор/маски ввода убраны;
форматы телефона и даты по-прежнему строго проверяет сервер. Admin получает подтверждение статуса.

Модуль 4 остаётся PARTIAL: нативный hover не подключён, GUI/Preview не проверены.
ER соответствует schema, но её экспорт средствами СУБД ещё не подтверждён.
Удалённый экзаменационный Git-сервер не указан. Старые AUDIT/GRADING относятся к прежней
версии и явно помечены; новый результат не приравнивается к официальным баллам.
