# Оценка с учётом уточнения преподавателя

Дата: 02.11.2026. Код сайта: commit `f0313a7`.
**Критерии 3.1–3.4 относятся к макету «Группа Таймыр».** Это уточнено пользователем.
Прежняя оценка 63,5/75 = 84,67% для сценария сайта больше не применяется.
Все приведённые баллы — предварительная модель, а не решение экзаменационной комиссии.

Источник: [«УП ИСП 406», подробные критерии](https://docs.google.com/spreadsheets/d/1qPOgaLSEp9ge5Wildnynw2j232VrXv2a6bH2XeV2PiU/edit#gid=0).
Проверены 21 критерий, заголовки и формулы обеих ведомостей.
[Снимок источника](grading-source.json) не содержит ФИО или оценок участников.

**67 нельзя называть уже набранными баллами.** Открытие, нативное отображение, сохранение
и проигрывание переходов не проверены. PNG являются референсами Pillow, а не экспортом
редактора. При непринятии макета под риском весь блок 25; сайт 48 составляет только 64%
от общего максимума 75. Это размер риска, не автоматический ноль от эксперта.

## Порог 85%

В каждом критерии выбирается уровень 0,1 или 2, затем применяется вес. Формулы SUMPRODUCT
дают максимумы 25+25+25= 75. Порог 85% — 63,75; следующий возможный общий итог — 64/75=85,33%.
При оценке сайта 48 нужно минимум **16/25 за макет**.

Если 1.6 снижен с 2 до 1 и 1.9 с 2 до 1, сайт получит 45,5 вместо 48. Тогда требуется 18,25,
следующий возможный результат блока макета — **18,5/25**. При условных 19 общий строгий
сценарий — **64,5/75 = 86%**, запас небольшой.

В предыдущем проходе прошли 15 тестов за 25,943 s, включая 62 реальные HTTP-проверки.
Edge-сценарий проверил все страницы, слайдер, формы, статусы и отзыв. После уточнения
сайт и макет не изменялись, функциональные проверки заново не запускались.

Небольшие ссылки, контраст и неполные состояния сайта остаются замечаниями качества.
**Они не вычитают баллы 3.1–3.4**, поскольку эти пункты оценивают макет.
Прежний расчёт +6,5 от правки CSS сайта для этих критериев отменён.

## Приоритеты для 85+ с запасом

1. **Открыть макет в допустимом редакторе и проверить оба экрана.** Проверить Roboto,
   переносы, сетку, обрезание/наложения, зоны, все тексты, переходы «Главная/Решения»,
   отсутствие переходов у остальных кнопок. Сохранить итоговый файл. Сам этот шаг
   не добавляет баллы поверх условных 19, а подтверждает пригодность макета.
2. **Подключить настоящий hover и нужные интерактивные состояния в макете.** Потенциал
   +6 по 3.3: общий условный итог **73/75 = 97,33%**. В строгом сценарии сайта 45,5 —
   **70,5/75 = 94%**. Баллы только после проверки поведения в редакторе.
3. **Обработать предоставленные фото в разрешённом графическом редакторе.** Сохранить
   экспорт и доказательство процесса. Потенциал +2 по 2.8; сайт до 50/50, общий до 75/75
   при полном зачёте остальных пунктов.
4. **Получить ER средствами разрешённого инструмента СУБД и улучшить читаемость длинных
   строк кода.** Снизить риск потери 2,5 по 1.6/1.9; после реальных правок повторить проверки.

Главный приоритет теперь — макет и подтверждение его работы в редакторе.
Переработка CSS сайта не заменяет выполнение критериев макета. Новые функции сайта,
страницы и библиотеки для достижения этого порога не требуются.
