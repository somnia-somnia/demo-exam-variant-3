# Компактная версия без Jinja

Дата: 03.11.2026. Исходная версия: f513383 (код сайта f0313a7), 512 строк / 30 110 символов.
Пользователь запросил обычный HTML/JavaScript без Jinja и сокращение примерно вдвое.

## Решения

- Один static/index.html: стандартные формы, секции и HTML template карточки. Никаких {% %},
  {{ }}, генерирования HTML в Python, клиентских шаблонизаторов или сборки.
- Flask отдаёт HTML по прежним URL и JSON через /api. POST по прежним адресам:
  успешный ответ JSON {next:...} с 200, ошибки JSON с 400/403/404/409; браузер переходит сам.
- /api возвращает csrf, минимальный профиль без password_hash, справочники и заявки,
  выбранные на сервере по реальному пользователю. Гость получает пустой список.
- DB/schema, имена полей и статусов, сессии, хеши, параметризованный SQL, CSRF, ограничения
  отзывов и завершённого статуса сохраняются. Существующая instance/rental.db не удаляется.
- Пользовательский текст выводится textContent, не innerHTML. Слайдер 4/3000ms/стрелки,
  Montserrat, палитра,390×844, все девять локальных изображений остаются.
- Модуль 4 не меняется. Код измеряется символами и строками, не одной минифицированной строкой.
- Первоначальная цель — примерно половина кода. После измерения пользователь 03.11.2026
  согласовал сокращение примерно на треть. Итог:20 527 символов,31,83% меньше 30 110;
  454 строки вместо 512;6 файлов сайта вместо 11. Минификация и сокращение имён не применялись.

## Журнал

- Начальная точка сохранена в ветке exam-solution; изменения — c/plain-html.
- Решение: обычный HTML template вместо сборки HTML строками. Это стандарт DOM браузера,
  переносит условия в явный JavaScript и сохраняет безопасный вывод пользовательских данных.
- Решение: бизнес-правила и структура БД важнее искусственной экономии последних строк.

## Осознанные изменения

- Все пять адресов страниц сохранены, но HTML один. POST теперь возвращает JSON next с 200,
  а не 302; браузер выполняет переход. API /api — новая точка получения состояния/CSRF/заявок.
- На каждой форме выводится общий список серверных ошибок. Нет Jinja, макросов и наследования.
- Для сокращения убраны необязательные маски телефона/даты, лишние рекламные тексты,
  большинство декоративных правил. Требуемые форматы проверяет сервер; placeholders сохранены.
- Карточки проще; фото и контакты своего заказа видны также владельцу. Admin по-прежнему
  получает все заявки. Сообщение изменения статуса восстановлено через sessionStorage.
- Убраны отдельные оформленные страницы HTTP-ошибок: GET использует стандартный ответ Flask,
  POST/API — JSON. Это не отключает проверки доступа и не раскрывает stacktrace (debug=False).
- Половина первоначального объёма не достигнута и не заявляется; согласованный результат — треть.
