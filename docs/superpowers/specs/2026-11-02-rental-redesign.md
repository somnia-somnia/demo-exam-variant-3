# Предметный сервис проката

Пользователь выбрал: фотографии моделей, чёткие формы и компактные заявки.
Сохраняются Flask/sqlite3, серверные проверки, палитра/Montserrat, 390×844 и слайдер
с четырьмя фото, стрелками на фото, счётчиком и автосменой 3000 мс без паузы.

## Аудит и основания
Свежие снимки `tmp/design-audit/`: вход desktop, регистрация desktop/mobile, вход mobile.
При 390×844 первое поле входа y=874, регистрации y=890: основная задача вне первого экрана.
Общие слоганы, одинаковые скруглённые панели, повторённые надзаголовки и декоративные
шаги создают шаблонную подачу. Иллюстрации почти не связаны с выбором и историей аренды.
Другие страницы прочитаны в исходниках; свежий визуальный аудит кабинетов будет после реализации.

## Решение
- Вход/регистрация: предметный заголовок «Аренда автомобилей», реальные названия моделей,
  четыре ранее оптимизированных исходных слайда: Creta, дорога, загородная поездка, ключи.
  Формы без большой обводки-карточки; на телефоне форма первая, иллюстрации ниже.
- Новая заявка: форма и иллюстрация автопарка; native select из трёх моделей остаётся.
- История: компактные строки с фото, датой, оплатой и статусом, отзыв отдельной строкой.
- Администратор: плотный список с данными клиента и фильтром; без фоновых коллажей.
- Общий включаемый шаблон заявки убирает дублирование между историей и администратором.
- Отступы/границы/типографика создают иерархию; оранжевый для действий и текущего статуса.
  Montserrat, H1=36, H2=24, H3=18, основной текст16, вспомогательный12 italic сохраняются.

## Материалы
В архиве сайта24 изображения включая варианты логотипов, ранее использовано6.
Добавляются оригинальные фото Vesta, автопарка и передачи ключей; Creta уже использовалась.
Решение после review: прежние4 слайда сохраняются, новые3 фото применяются в рабочих
экранах. Так используются9 разных исходных изображений с логотипами, без дублирования файлов.
Изображения иных моделей не выдаются за доступные автомобили. Для Toyota Camry нет
проверенного фото именно этой модели: используется общий автопарк с соответствующим alt.
Нет выдуманных цен, скидок, адресов, графика работы или обещаний состояния автомобилей.
Файлы «Медиа» для Таймыра не смешиваются с автопрокатом.

## Объём и проверка
База сравнения:546 строк,490 непустых,30642 символа,10 исходных файлов сайта.
Уменьшать реальный объём CSS/HTML и повторение, сохраняя понятность. Удаление пустых
строк или уплотнение операторов не считается упрощением. Backend-проверки не сокращать.
Тест перед изменением: первое поле login в mobile viewport. После: полный браузерный
сценарий, 11 функциональных тестов, screenshot QA входа/регистрации/заявки/истории/admin,
контроль сети/локальных фото/ширины, независимый review. Статистику обновить честно.
