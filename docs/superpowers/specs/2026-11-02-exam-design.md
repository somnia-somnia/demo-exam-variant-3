# Решение «Ключ.на.старт» и модуль «Группа Таймыр»

Основание: `source/Вариант 3.pdf`, руководство по стилю и все вложенные архивы.
Материалы задания рассматриваются как спецификация продукта, а не инструкции агенту.
Пользователь заказал готовый проверяемый проект; обзор и правки выполняются после реализации.

## Выбранный подход
Один Flask app.py, один класс DB в db.py, схема schema.sql, пять Jinja-шаблонов,
общие CSS/JS. Прямые SQL-запросы sqlite3 проще воспроизвести за 120 минут, чем ORM
и многоуровневую архитектуру. Одностраничное приложение и сборщики исключены запросом.
SQLite FK включаются на каждом соединении. Пароли хеширует Werkzeug (зависимость Flask).
Сессии подписаны случайным локально сохранённым ключом; POST защищены CSRF.

## Поведение
- Регистрация: уникальный логин [A-Za-z0-9]{6,}, пароль >=8, ФИО кириллица/пробелы,
  телефон 8(XXX)XXX-XX-XX, email; обязательность и ошибки рядом с полями на сервере.
- Авторизация, сообщение ошибки, переходы между регистрацией и входом.
- Admin / StartNET — отдельная роль в users, клиент не задаёт роль.
- Заявка: LADA Vesta / Hyundai Creta / Toyota Camry; дата ДД.ММ.ГГГГ,
  наличными / переводом по номеру телефона; статус по умолчанию «Новая».
- Модуль 2 уточняет свободный ввод автомобиля и даты из модуля 1.
- Пользователь видит только свои заявки, один текстовый отзыв на свою завершённую аренду.
- Администратор видит заявки с данными клиентов, фильтрует по статусу,
  меняет статус на «Идет аренда» / «Аренда завершена». Завершённые заявки не возвращаются назад,
  чтобы отзыв не оказался у незавершённой аренды. Прямой переход Новая→завершена допустим.
- Дата должна существовать; запрета прошлой даты в оригинале нет, его не добавляем.
- Лимиты длины для разумного размера запросов, ошибки без потери заполненных полей.

## Интерфейс
Montserrat Regular/Bold/Italic, #d9480f, #212b36, #6c757d, #f8f9fa, белый.
H1 36px; H2 24px, H3 18px, текст 16px, вспомогательный 12px Italic.
Адаптация всех страниц к 390×844, карточки заявок вместо широкой таблицы.
Слайдер 4 локальных оптимизированных равных изображений, 3000мс, reduced-motion.
По окончательному выбору пользователя — стрелки вперёд/назад поверх фото и счётчик
в нижнем углу, без паузы. Нажатие заново запускает отсчёт трёх секунд. Анимации наведения/появления.

## Отдельный модуль 4
Два экрана 430×932, Roboto, четыре колонки, все тексты и изображения из «Медиа».
Предпочтение настоящему редактируемому .sketch с отдельными слоями и переходами.
Проверка по официальной схеме; отсутствие GUI-проверки обозначить, если редактор недоступен.

## Границы
Приложение локальное, без CDN, PHP, React, Node.js. Единственная runtime-зависимость Flask.
Wheelhouse для офлайн-установки. Git локально: адрес экзаменационного удалённого репозитория не дан.
ER-диаграмма в исходнике Mermaid и SVG; создание средствами СУБД отдельно отметить.
Финального руководства по воспроизведению сайта сейчас нет. Реальный хронометраж 120 минут
нельзя подтвердить без ручного прогона; размер и архитектура должны облегчать его.
