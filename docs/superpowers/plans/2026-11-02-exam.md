# Exam Implementation Plan

> **For agentic workers:** use superpowers:executing-plans for the site; module 4 is independent.

**Goal:** Рабочее локальное решение с проверками и отдельным дизайнерским артефактом.
**Architecture:** Flask + sqlite3, один класс DB, 5 Jinja-шаблонов, общие CSS/JS.
**Tech Stack:** Python, Flask, SQLite3, HTML/CSS/JS; unittest и Playwright только для проверки.
**Spec:** ../specs/2026-11-02-exam-design.md

## Global Constraints
Локальные ресурсы, никакого Node.js/CDN/ORM. Воспроизведение целится в 120 из 150 минут.
Без финального руководства воспроизведения. Документировать реальные ограничения.

## Review Focus
- Подмена owner/id/role и SQL-инъекции не открывают чужие заявки.
- Невозможные даты, пробелы, пустые и слишком длинные значения возвращают ошибки формы.
- Отзыв нельзя оставить заранее, дважды или на чужую заявку.
- Подделка статуса и запрос без CSRF отклоняются сервером.
- На 390px формы/карточки не выходят за экран, слайдер меняется через 3с.
