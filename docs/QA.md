# Проверка Django + MySQL

06.11.2026. База изменения: Git `0d72dbc` (Flask + SQLite).

Проверочная среда: официальный Windows x64 Python 3.11.9, Django 5.2.19,
mysqlclient 2.3.0, настоящий MySQL Community Server 8.4.13 на localhost:3307.
Сервер распакован локально без установки системной службы. БД тестов
изолированы, рабочая SQLite не используется приложением и не очищается.

- Серверные сценарии: обязательность и форматы полей, граничные значения,
  отсутствие прежних верхних лимитов, уникальность логина, хеши, роли,
  владение, FK, создание трёх машин с двумя оплатами, строгая календарная
  дата, статусы и фильтр, отзыв только после завершения, повторные и длинные
  отзывы, возврат статуса, CSRF, большие ID, XSS, POST logout.
- Полный прогон: 28 тестов, OK. В том числе два реальных параллельных
  запроса: смена статуса ждёт commit уже проверенного отзыва.
- Вставка проверена после ADD COLUMN note ... FIRST в MySQL: новая
  регистрация/вход успешны при изменённом физическом порядке столбцов.
- HTTP: отдельный Django-процесс и отдельная MySQL БД; четыре независимых
  cookie jar. Регистрация → вход → заявки → статусы → отзывы → выход.
- Legacy-import: SQLite с переупорядоченными полями и дополнительными
  столбцами, прежний scrypt-хеш, ненулевые ID пользователя/заявки/отзыва.
  Импорт в MySQL сохраняет значения и ID, повторный импорт в занятую БД
  запрещён. SHA-256 исходного файла до/после одинаков.
- Существующий instance/rental.db также перенесён в рабочую MySQL;
  SHA-256 исходного SQLite не изменился.
- MySQL: CHECK TABLE=OK, PK/FK/UNIQUE проверены по метаданным,
  вставка ссылки на отсутствующего пользователя отвергается. ER SVG/Mermaid
  и SQL созданы по свежей реальной MySQL-схеме. `db-verification.json`.
- Edge headless/CDP: 390×844 и 1440×1000; публичная главная, три модели,
  слайдер перед каталогом, четыре слайда/3000 мс, стрелки и сброс таймера;
  формы без фотографий, ошибки, полный цикл заявки, фильтр и экранирование
  XSS; отсутствие переполнения, сломанных изображений, внешних запросов
  и исключений JS. Скриншоты просмотрены визуально.
- Офлайн: установка в пустую папку с --no-index и только локальными wheels;
  импорт Django/MySQLdb/Werkzeug проверен в Python 3.11.9.
- Независимое read-only ревью: доступ, CSRF, именованные ORM-вставки,
  сохранность SQLite, состав счётчика. Найденные замечания к надписи
  кнопки и конкурентной смене статуса исправлены до окончательного прогона.

Отчёты: `test-results.txt`, `http-results.json`, `browser-results.json`,
`db-verification.json`, `offline-install.txt`, `line-statistics.json`.
Скриншоты сохраняются в `screenshots/`.
Точное число тестов и время — в последнем test-results.txt.

Бюджет считает весь runtime сайта: app.py, config.py, rental/*.py, все HTML,
CSS/JS и requirements.txt. Нет сжатого/закодированного кода или необходимой
логики вне счётчика. tools/import_legacy.py — одноразовая миграция,
не нужна для чистого запуска; её объём приведён отдельно в STATISTICS.md.

Доказательства являются инженерной проверкой, не гарантией оценки экзамена
или времени ручного воспроизведения. Модуль 4 и финальные руководства
в этой итерации не редактировались.
