# Сверка с заданием и ограничения

Обновлено 06.11.2026. Основной источник: оригинальный `original/Вариант 3.pdf`,
руководство по стилю и `original/Текст.docx`, извлечённые из приложенного архива.
`source-manifest.json` содержит SHA-256, состав всех вложенных ZIP, размеры изображений
и имена шрифтов. Совпадение сохранённых оригиналов с архивом проверено по SHA-256.
Инструкции организатора из PDF рассматриваются как условия экзамена;
они не дают разрешения публиковать файлы или менять внешние сервисы.

Дополнительные решения: логин ограничен 40 символами, пароль 128, ФИО 150,
email 254, отзыв 2000; завершённая аренда не возвращается в работу.
Прошлые даты не запрещены: такого ограничения в оригинальном задании нет.
Дата без времени выбрана по уточнению модуля 2. Изменения выполнены с сохранением
существующей пользовательской БД, тесты используют отдельные временные базы.
Сессии прекращаются при перезапуске сервера; аккаунты и данные сохраняются.
В новой DDL убраны необязательные временные отметки и отдельный индекс FK;
PK/FK/UNIQUE/CHECK и все серверные ограничения сохранены. Старые таблицы
при запуске не изменяются. Необязательные фото карточек, счётчик слайдера и
уведомления об успехе удалены; общий CSS обеспечивает гибкую ширину до 700 px.

В запросе одновременно названы MySQL-совместимая БД и SQLite. Реализована
явно указанная в пункте 9 SQLite: отдельного сервера нет. Это не MySQL-совместимый
движок и не обещание запуска schema.sql на MySQL. Если на экзамене обязательно
подключение к общему серверу MySQL, потребуется согласовать и заменить адаптер/DDL.

Офлайн-wheel для бинарной зависимости MarkupSafe приложен для Windows x64
Python 3.11 и 3.12. Для другой ОС/архитектуры пакет надо подготовить заранее.
Сам Python предполагается установленным. Проверочный portable Python лежит
в игнорируемом tmp, не является частью исходников и не нужен на экзамене.
