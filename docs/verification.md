## Исправления по результатам проверки

- Вспомогательный запрос unittest закрывает соединение явно: sqlite3-контекст сам по себе
  делает commit/rollback, но не закрывает файл; в Windows это мешало очистке временной БД.
- Unicode в поддельном CSRF не приводит к TypeError: сравниваются байты.
- HTML-атрибут height больше не растягивает фото: CSS height:auto и проверка пропорций.
- UPDATE статуса содержит условие, не позволяющее перезаписать завершённую аренду
  конкурирующим запросом.
- Независимый обзор выявил ограничение мобильных клавиатур: телефон/дата требуют
  разделителей. Добавлены маски; ввод цифр через Edge CDP Input.insertText проверяет
  получение `8(999)123-45-67` и `02.12.2026` в реальных DOM-полях.

## Что проверка не подтверждает

Native Sketch GUI/CoreText/prototype playback и hover не тестировались. Самостоятельный
экзаменационный ввод за 120 минут не проводился. Экспорт ER из GUI СУБД и передача в
удалённый экзаменационный Git не выполнялись. Эти пункты перечислены в requirements.md.
