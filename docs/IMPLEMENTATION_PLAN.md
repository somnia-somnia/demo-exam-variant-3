Дата: 05.11.2026. Основание — запрос пользователя и оригинальные PDF/DOCX в архиве.
Это рабочий план разработки, не руководство по ручному воспроизведению.

Архитектура: Python 3.11, Flask, SQLite, один класс DB, SQL-схема,
серверные HTML-шаблоны, общий CSS и короткий JS слайдера. Существующую
пользовательскую БД сохраняем. SQLite выбрана по прямому пункту 9 запроса;
совместимость с сервером MySQL не заявляется.

Особое внимание: чужие заявки и поддельная роль; пустые/неверные значения и дубликаты;
отзыв до завершения или повторно; HTML в отзыве; потеря данных и статуса после перезапуска.
Ручной набор оценивается по символам. 10–12 тысяч строк не соответствуют времени
120 минут при 100–120 символах/мин. Объём не раздуваем и выполнимость не обещаем.
